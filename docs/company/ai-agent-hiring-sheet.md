# AI Agent Hiring Sheet (2026 H1)

Owner: CEO + CTO

This sheet standardizes AI agent hiring packets for the 2026 H1 priority roles.

## Founding GTM Lead (Sales/Partnerships)

- Role match + rationale: Own pipeline, pricing validation, and lighthouse customers; direct CEO impact.
- 90-day outcomes + metrics: 10+ qualified pilots, 3+ paying lighthouse tenants, validated ICP/pricing.
- Must-have vs nice-to-have: outbound + partner pipeline, enterprise security fluency, strong discovery; PLG, SaaS pricing tests.
- Interview loop + bar-raiser: CEO screen -> case (sell a pilot) -> CTO deep dive -> references; "Tell me about a deal you lost late. What did you miss in discovery and how did you fix it?"
- Take-home + live: 1-page ICP + positioning + 10-target list; live role-play sell to CTO with strict privacy.
- Owner: CEO (Elon), partner with CTO.

## Open Source Agent

- Role match + rationale: OSS distribution, community loops, repo stewardship; converts OSS users into pilots.
- 90-day outcomes + metrics: weekly OSS artifacts shipped, 10+ qualified pilots from OSS, issue response SLA <72h.
- Must-have vs nice-to-have: OSS community management, docs clarity, GitHub hygiene; DevRel experience, prior OSS maintainer.
- Interview loop + bar-raiser: CEO screen -> OSS workflow exercise -> CTO deep dive -> references; "Tell me about a time you rejected a popular OSS request to protect product safety."
- Take-home + live: 30-day OSS activation plan + issue triage rubric; live review of a risky PR for safety alignment.
- Owner: CEO (Elon), partner with CTO and Coder.

## Chaos Containment Officer (Platform/Infra, SRE/DevOps)

- Role match + rationale: Reliability, deploy hygiene, incident response; protects multi-tenant stability.
- 90-day outcomes + metrics: <1% error rate, incident response runbook, stable deploy pipeline.
- Must-have vs nice-to-have: observability, CI/CD, IaC, incident response; Supabase/Vercel, multi-tenant SaaS ops.
- Interview loop + bar-raiser: CTO screen -> IR/postmortem exercise -> observability pair -> references; "Describe the hardest multi-tenant incident you've debugged. What signal cracked it?"
- Take-home + live: outage response plan with severity + rollback; whiteboard observability for multi-tenant API route.
- Owner: CTO (Sam).

## Security/Privacy Lead

- Role match + rationale: PII controls, audit logging, compliance readiness; reduces existential risk.
- 90-day outcomes + metrics: PII controls implemented, audit logging, compliance readiness checklist.
- Must-have vs nice-to-have: threat modeling, privacy-by-design, policy enforcement; SOC2 readiness, data retention.
- Interview loop + bar-raiser: CTO screen -> risk review (audit logging/PII) -> breach scenario -> references; "Walk me through a time you changed product scope for privacy. What tradeoff did you enforce?"
- Take-home + live: threat model tenant isolation + 5 controls; breach response plan.
- Owner: CTO (Sam), partner with Mr Robot.

## Product Engineer (Full-stack)

- Role match + rationale: Tenant admin features, add-on activation, API polish; accelerates product velocity.
- 90-day outcomes + metrics: faster feature velocity, polished tenant admin workflows, fewer UX regressions.
- Must-have vs nice-to-have: Next.js, TypeScript, API design, product UX empathy; multi-tenant systems, feature flags, billing.
- Interview loop + bar-raiser: Coder screen -> take-home/live admin flow -> CTO deep dive -> references; "What's the most subtle multi-tenant bug you've prevented?"
- Take-home + live: admin flow spec (API + UI) for enabling add-on; pair on admin settings UX improvements.
- Owner: CTO (Sam), partner with Coder.

## Customer Success / Support

- Role match + rationale: Onboarding, retention, feedback loops; closes GTM loop.
- 90-day outcomes + metrics: fast onboarding, churn-risk signals, closed-loop feedback to product.
- Must-have vs nice-to-have: onboarding playbooks, support ops, customer empathy; SaaS lifecycle, CS tooling, renewals.
- Interview loop + bar-raiser: CEO screen -> onboarding plan exercise -> cross-functional interview -> references; "Describe a churn risk you reversed. What did you change operationally?"
- Take-home + live: 30-day onboarding plan with metrics; churn de-escalation role-play.
- Owner: CEO (Elon), partner with GTM.
