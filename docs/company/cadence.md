# Operating Cadence

Owner: CEO + CTO
Maintainer: Coder

This doc defines the operating rituals, owners, and required artifacts. Keep it lightweight and consistent.

## Weekly Rituals

### 1) Weekly Business Review (WBR)
- Owner: CEO
- When: Monday
- Artifacts:
  - Revenue + pipeline snapshot
  - Top 5 risks + mitigations
  - Hiring funnel status

### 2) Roadmap Review
- Owner: CTO
- When: Tuesday
- Artifacts:
  - Current quarter goals
  - Next 2-week sprint priorities
  - Dependency risks

### 3) Incident Review
- Owner: Linus
- When: Wednesday
- Artifacts:
  - Incident summary (if any)
  - Root cause + corrective actions
  - Follow-up owners

### 4) Hiring Review
- Owner: CEO + CTO
- When: Thursday
- Artifacts:
  - Role briefs and funnel health
  - Candidate quality bar status
  - Close plan for active candidates

### 5) Weekly Retro
- Owner: Coder
- When: Friday
- Artifacts:
  - What shipped vs planned
  - What blocked progress
  - Process improvements

## Monthly Rituals

### 1) Metrics + Scorecard Review
- Owner: CTO
- Artifacts:
  - Role scorecards (see `docs/company/metrics.md`)
  - Quality and reliability trend

### 2) Ops & Security Review
- Owner: Mr Robot + Linus
- Artifacts:
  - Security posture changes
  - Audit log highlights
  - Reliability SLO compliance

### 3) GTM Review
- Owner: CEO
- Artifacts:
  - Pipeline velocity
  - Conversion rates
  - Customer feedback summary

## Quarterly Rituals

### 1) OKR Review + Reset
- Owner: CEO + CTO
- Artifacts:
  - OKR scorecard (see `docs/company/okrs.md`)
  - Next quarter OKRs

### 2) Agent Performance Review
- Owner: CTO
- Artifacts:
  - Quarterly review notes (see `docs/company/ai-agent-feedback.md`)
