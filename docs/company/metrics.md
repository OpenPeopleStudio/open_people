# Role Scorecards and Metrics

Owner: CTO
Maintainer: Coder

Lightweight scorecards per role. Update monthly. Track trend, not perfection.

## Core Scorecards

### CEO (Elon)
- Pipeline velocity (new qualified pilots / week)
- Lighthouse conversions (quarter)
- Strategic clarity (OKR alignment score, 1-5)

### CTO (Sam)
- Release reliability (% releases without rollback)
- Cycle time (idea → shipped, days)
- Tenant safety incidents (count / month)

### Coder
- Doc freshness (% docs updated in last 30 days)
- Navigation quality (broken links = 0)
- Task clarity (tasks with success metrics + validation steps)

### Lisa
- UX regression rate (reported issues / release)
- UX completion lead time (days)
- Usability score (internal review 1-5)

### Mr Robot
- Security incidents (count / month)
- PII logging violations (count / month)
- Auth/tenant review coverage (% of risky changes)

### Linus
- API uptime (% monthly)
- Incident MTTR (hours)
- Queue latency p95 (seconds)

### Claude
- Cross-slice completion rate (% of large-slice tasks shipped)
- Integration bug count (per release)
- API contract drift (count / month)

## AI Agents

### Zuck (GTM)
- Qualified pipeline created (count / week)
- Pilot conversion rate (%)
- Content output cadence (artifacts / week)

### Open Source Agent
- OSS adoption (stars, forks, installs)
- OSS → pilot conversion rate (%)
- Issue response SLA (hours)

## Metric Notes

- Track trend lines monthly.
- Any metric with two consecutive regressions requires a mitigation plan.
